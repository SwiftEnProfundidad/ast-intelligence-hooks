# Pumuki public enterprise README

## Why

Pumuki needs a public README suitable for GitHub, npm and external enterprise evaluation. The current public surface mixes operational history with product explanation, which makes adoption harder for teams evaluating the framework.

## What Changes

- Rebuild the root README as an enterprise product landing page.
- Add a clean governance-flow diagram for the README.
- Update public npm metadata only where it improves package discovery.
- Keep runtime, rule packs, hooks, binaries and package version unchanged.

## Impact

- Documentation-only product packaging change.
- No runtime behavior changes.
- No npm publication in this change.
